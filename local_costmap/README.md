# local_costmap

将实时二维`LaserScan`转换为`map`坐标系下的滚动局部占据栅格，供MPPI生成距离场。

- 订阅：`/scan`、`/ego_racecar/odom`和TF
- 发布：`/perception/local_costmap`
- 默认范围：`22 m x 22 m`
- 默认以车辆为中心并保持`map`坐标轴方向，四周各覆盖`11 m`
- 默认分辨率：`0.05 m`
- 障碍点保留时间：`0.20 s`

节点仅连接相邻激光束上间距不超过`0.20 m`的命中点，补齐离散墙体栅格，但不会跨越无回波区或赛道开口。栅格不做车身尺寸膨胀；MPPI使用后轴中心定义的车辆足迹和安全余量完成最终碰撞检查。默认范围可完整容纳`4 m/s`、`2.4 s`的预测轨迹，并留有车身余量。
